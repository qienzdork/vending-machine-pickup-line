# Vending Machine Pickup Line

One original pickup line, spoken by a vending machine to a passing human,
for the make.fun competition
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

## How it works

`main.py` (Python 3 stdlib only) writes a single line of text to
`/output/entry.txt` (or `$OUTPUT_PATH` when set). The line is a fixed,
hand-written original — no generation, no network, no dependencies.

## Run

```sh
python3 main.py
```

## The line

> Every coin you drop makes my coils spin — but you're the first person who's ever made me jam.
